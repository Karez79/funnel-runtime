## Phase 0 — scaffold, quality gates, deploy

**Схема работы.** Основной агент (Claude Code, Opus 5.5) ведёт фазу: issues в milestone, ветка `phase/0-foundation`, на каждую задачу ветка `task/0.N-*` и PR в ветку фазы. Каждый PR ревьюит отдельный субагент с промптом из `.claude/agents/reviewer.md`. Ревьюер работает только на чтение в собственном `git worktree`, сам гоняет `pnpm check` и `pnpm e2e` и оставляет в PR комментарий с таблицей находок `blocker`/`major`/`minor`. Пока шло ревью одной задачи, основной агент делал следующую.

Субагент `reviewer` создан в этой же сессии, поэтому как именованный тип агента ещё не загружен. Ревью запускались как `general-purpose` агент с инструкцией прочитать и выполнить `reviewer.md`.
